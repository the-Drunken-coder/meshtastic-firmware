# Matt Pocock skills (vendored)

These `matt-*` skills are copied from [the-Drunken-coder/mattpocock-skills-community](https://github.com/the-Drunken-coder/mattpocock-skills-community) at commit `49a78c6` (package version `0.2.0+upstream.d81f3a18`), an unofficial Codex packaging of [mattpocock/skills](https://github.com/mattpocock/skills). They are MIT-licensed; see `LICENSE.mattpocock-skills`.

Codex discovers repository skills in `.agents/skills/`, so they are available in this checkout without installing the Codex plugin. If the `mattpocock-skills-community` plugin is also installed, the skills are identical; prefer one source.

To refresh, copy `skills/` from an updated checkout of that repository over this directory.

This fork-only setup must not be sent upstream to meshtastic/firmware.
