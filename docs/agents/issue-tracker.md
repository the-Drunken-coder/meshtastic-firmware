# Issue tracker: workspace GitHub Issues

All specifications, tickets, decisions, and triage for these forks live on `the-Drunken-coder/meshtastic-workspace`.

Read the [workspace tracker instructions](../../../docs/agents/issue-tracker.md) before tracker operations, including its artifact-kind conventions. In a standalone firmware clone, read the [canonical workspace tracker instructions](https://github.com/the-Drunken-coder/meshtastic-workspace/blob/main/docs/agents/issue-tracker.md).

Use `gh` with `--repo the-Drunken-coder/meshtastic-workspace` for issue commands, or the matching workspace REST API endpoint. Firmware changes and pushes remain in `the-Drunken-coder/meshtastic-firmware`. Child fork Issues are disabled.

Keep local `.scratch/` notes out of commits. Upstream issues or pull requests require explicit user authorization.
